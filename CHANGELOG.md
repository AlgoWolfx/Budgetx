# Changelog

Bu dosya projedeki tüm önemli değişiklikleri içerir.

Format [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) temel alınmıştır,
ve bu proje [Semantic Versioning](https://semver.org/spec/v2.0.0.html) kullanır.

## [1.0.0] - 2025-01-02

### ✨ Added
- 💰 Gelir ve gider takip sistemi
- 📊 Interaktif grafikler ve analizler (Recharts)
- 📱 Tam responsive tasarım (mobil, tablet, desktop)
- 🌓 Dark/Light tema desteği
- 💶 Euro para birimi desteği (tr-TR locale)
- ⚡ Hızlı gider giriş şablonları
- 📅 Aylık bütçe yönetimi
- 🔒 Şifre korumalı erişim
- 📈 Kategori bazlı harcama analizi
- 📊 Yıllık finansal raporlar
- 💾 Yerel veri depolama (localStorage)
- 🎯 Modern ve temiz kullanıcı arayüzü

### 🛠️ Technical Features
- React 18.3.1 ile modern komponent yapısı
- TypeScript ile tip güvenli geliştirme
- Vite ile hızlı build ve geliştirme
- Tailwind CSS ile utility-first styling
- ShadCN UI ile profesyonel bileşenler
- Zustand ile lightweight state management
- React Router DOM ile client-side routing
- ESLint ile kod kalitesi kontrolü

### 📱 User Experience
- Mobile-first responsive tasarım
- Smooth animasyonlar ve geçişler
- Intuitive navigation ve kullanım
- Accessibility standartlarına uyum
- Cross-browser uyumluluğu
- Performance optimizasyonları

### 🚀 Deployment
- GitHub Pages desteği
- CI/CD pipeline (GitHub Actions)
- Automated testing ve build
- Production optimizasyonları

### Changelog Formatı

- `Added` - Yeni özellikler
- `Changed` - Mevcut işlevsellikte değişiklikler
- `Deprecated` - Yakında kaldırılacak özellikler
- `Removed` - Kaldırılan özellikler
- `Fixed` - Hata düzeltmeleri
- `Security` - Güvenlik güncellemeleri
