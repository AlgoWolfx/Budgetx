# LifeManagement Budget

A personal finance dashboard for tracking income, expenses, categories and monthly spending patterns.

Built as a front-end focused project to practice typed React application development, state management, data visualization and responsive UI design.

## Features

- Income and expense tracking
- Category-based spending analysis
- Monthly and annual reporting
- Reusable expense templates
- Responsive dashboard
- Light/dark theme support
- Local persistence
- Charts and visual summaries

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Zustand
- TanStack React Query
- Recharts
- Zod
- React Hook Form

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Scope

This project focuses on front-end application structure and personal-finance visualization. Data is currently stored locally rather than in a multi-user cloud backend.
